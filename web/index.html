快速启动 一条命令

首次启动自动建库并播种演示数据

# 1) 安装依赖（仅 3 个包）
python -m pip install -r requirements.txt

# 2) 启动（首次会自动播种 12 景区 / 8 剧本 / 439 条素材）
#    默认 8770；若被占用会自动改用其它端口，请以终端提示为准
python run.py

# 3) 重新播种演示数据（可选）
python run.py --reseed

# 4) 一次跑完全部五套验证（推荐）
python tests/run_all.py --start

# 5) 只看数据体检（可选）
python tests/inspect_data.py
